# H5 运行图片导出规范

卡博士 H5 以 375 CSS px 为主要手机基准。运行图片放在 src/assets/；设计原件与测试证据另行保存。

- 按页面槽位分规格，不把所有图片压成同一尺寸。位图一般使用实际显示宽高的 2–3 倍输出；小头像 192×192，64 px 图标 192×192。
- 圆形头像的静态画面按 CSS object-cover 相同的居中区域裁正方形，其他图片保留原生比例，特别是透明人物、商品包装、含字宣传图。
- 满屏横幅和品牌长图参考 375 CSS px × 3，即宽度约 1125 px；细节多的长图优先保持文字可读。
- 已合适的会员卡面 770×450、小商品图和矢量 SVG 不做反复有损压缩。
- 首页历史 375×210 单倍图 home-banner-carousel.webp 需要原始设计高清图才能真正改善清晰度；禁止简单放大伪造分辨率。
- 使用中的图片才保留在 src/assets；删除前查真实代码引用。docs/、delivery/、design-export/ 中的原稿或历史截图不作为运行时垃圾清理。
- npm run verify:images 现有门禁检查 WebP 格式和 500 KiB 单文件上限；不能替代像素与真机视觉验收。
